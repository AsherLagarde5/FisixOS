# VMU standalone mini-app, v0.2, not v0.1
VMU detached from controller runs its own 8-bit
Sanyo LC86K87 CPU, 48x32 LCD, 32 KB program max,
512 bytes RAM, 6 buttons. That code is NOT SH-4
code, it is LC86 code, with a different toolchain.
v0.1 VMU use is docked only: Dreamcast SH-4 updates
VMU LCD over Maple bus as a second status screen.
v0.2 standalone app will show FISIX logo, user name,
and a tiny clock/Pong, when VMU is removed.
